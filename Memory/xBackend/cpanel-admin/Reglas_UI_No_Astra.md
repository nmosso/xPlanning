# Memoria Técnica: Directiva de Branding UI No-Astra

| Metadato | Detalle |
| :--- | :--- |
| **Proyecto:** | `xBackend` |
| **Componente:** | `cpanel-admin` |
| **Funcionalidad:** | Estandarización de Nomenclatura y Regla No-Astra |
| **Fecha:** | 2026-10-03 |
| **Estado:** | Activo |

---

## 1. Resumen y Contexto
Por directiva de producto y de marca del ecosistema xIPTV, se prohíbe exponer términos técnicos de terceros como "Astra" o "Astraserver" a operadores y administradores finales.

---

## 2. Decisiones Técnicas y Directiva de Nomenclatura
- **Términos Prohibidos:** "Astra", "Astraserver", "Cesbo Astra".
- **Términos Neutros Estandarizados:**
  - *"Servidor"*
  - *"Servidor de Transmisión"*
  - *"Encoder"*
  - *"Servidor de Streaming"*

---

## 3. Alcance de la Regla
Aplica a títulos, textos de botones, modales, placeholders, tooltips, etiquetas de formularios y mensajes de error en `cpanel-admin`.
