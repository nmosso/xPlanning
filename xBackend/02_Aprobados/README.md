# xBackend - Carpeta de Requerimientos Aprobados

En este directorio se almacenan exclusivamente los documentos de requerimientos técnicos que han superado los filtros doctrinales y cuentan con la **aprobación formal del usuario**.

### Reglas de este directorio:
1. Los documentos aquí contenidos se consideran congelados (*frozen specifications*).
2. Son la base de referencia contractual para iniciar el desarrollo e implementación en el repositorio `xBackend`.
3. Cualquier cambio significativo posterior debe ser debatido y registrado como una nueva versión o un ajuste complementario.
4. Cuando la implementación se complete y pase a producción, el documento puede ser archivado en `../03_Historico/`.
