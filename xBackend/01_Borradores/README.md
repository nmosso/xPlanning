# xBackend - Carpeta de Borradores (Drafts)

En este directorio se crean y editan los documentos de requerimientos técnicos que se encuentran actualmente en fase de discusión o maduración para **`xBackend`**.

### Reglas de este directorio:
1. Usar las plantillas oficiales de `../../01_Plantillas/`.
2. Nomenclatura sugerida:
   - Para nuevas implementaciones: `REQ-[AÑO]-[NRO]_[nombre_corto].md` (ej. `REQ-2026-001_sincronizacion_gracenote.md`).
   - Para ajustes o correcciones: `FIX-[AÑO]-[NRO]_[nombre_corto].md` (ej. `FIX-2026-001_timeout_tmdb.md`).
3. Un documento permanece en esta carpeta hasta que el usuario manifieste formalmente su aprobación.
4. Una vez aprobado, el documento debe trasladarse a `../02_Aprobados/`.
