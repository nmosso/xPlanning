# Cross_System - Carpeta de Borradores (Drafts)

En este directorio se crean y debaten especificaciones técnicas para requerimientos transversales que impactan tanto a **`xBackend`** como a **`xManager`** (ej. nuevos flujos end-to-end, sincronización distribuida, nuevas entidades administrables desde CPanel que ejecutan tareas en nodos).

### Reglas de este directorio:
1. Usar las plantillas oficiales de `../../01_Plantillas/`.
2. Identificar con claridad meridiana qué parte de la solución corresponde a `xBackend` y qué parte a `xManager`.
3. Validar el impacto de red y la coherencia de contratos entre ambos sistemas.
4. Tras la aprobación explícita del usuario, trasladar el documento a `../02_Aprobados/`.
