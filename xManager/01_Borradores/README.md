# xManager - Carpeta de Borradores (Drafts)

En este directorio se gestionan las discusiones y especificaciones técnicas preliminares correspondientes al sistema **`xManager`** (nodos distribuidos, flujos multicast/IPTV, moduladores ISDB-T, transcodificación y hardware).

### Reglas de este directorio:
1. Usar las plantillas oficiales de `../../01_Plantillas/`.
2. Nomenclatura sugerida:
   - Para nuevas implementaciones: `REQ-[AÑO]-[NRO]_[nombre_corto].md` (ej. `REQ-2026-002_control_modulador.md`).
   - Para ajustes o correcciones: `FIX-[AÑO]-[NRO]_[nombre_corto].md` (ej. `FIX-2026-002_buffer_multicast.md`).
3. Todo documento se mantiene en borrador hasta la confirmación explícita del usuario.
4. Tras la aprobación, se traslada a `../02_Aprobados/`.
